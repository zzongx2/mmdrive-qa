# Towards Radar-Aware VLM-Based Autonomous Driving via mmWave Radar-Vision-Language Reasoning

**Research manuscript**

This work investigates how vision-language models can use mmWave radar evidence for driving question answering.

We introduce **mmDrive-QA**, a benchmark containing 2,019 multiple-choice questions across eight driving scenarios and four reasoning categories. We also introduce **mmPointRet**, a question-guided retriever that selects relevant radar points and provides them as textual input to vision-language models without modifying their architectures.
